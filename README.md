**Деплой сайта «Graphical History»**  
Сайт: https://www.testingsiten3p.online/; https://testingsiten3p.online/

**Описание проекта**  

Данный репозиторий содержит инфраструктурный код и исходные файлы для автоматизированного развертывания веб-сайта исторической тематики. Деплой реализован в виде двухконтейнерной архитектуры (веб-сервер и reverse-прокси) с использованием Docker Compose. Проект также включает Ansible-плейбуки для подготовки серверов и развертывания стека мониторинга.

**Назначение файлов и директорий**  


site.html — исходный код главной страницы сайта. Выступает в роли индексного файла, который отдается пользователям при заходе на домен.  


nginx.conf — конфигурация прокси-сервера Nginx. Настраивает маршрутизацию, обработку основного домена и поддомена www, а также проброс запросов (proxy_pass) к backend-контейнеру.  


Dockerfile — инструкции для сборки базового Docker-образа. Очищает стандартную директорию Nginx и копирует файл site.html внутрь контейнера.  


docker-compose.yml — файл оркестрации. Поднимает изолированную сеть и связывает два сервиса: контейнер с исходниками сайта (history_site) и внешний прокси-сервер (nginx_proxy), пробрасывая нужные тома (volumes).  


inventory.ini — конфигурационный файл Ansible, содержащий адреса целевых серверов (Target Nodes) и параметры подключения по SSH для удаленного управления.  


monitoring.yml — Ansible-плейбук, описывающий автоматизированные шаги по установке и настройке стека мониторинга (Prometheus, Grafana и экспортеры).  


vars.yml — файл с переменными для Ansible. Хранит гибкие настройки, пути и параметры, которые подставляются в плейбуки при их выполнении.  


template/ — директория для хранения Jinja2-шаблонов (например, prometheus.yml.j2). Ansible использует их для динамической генерации конфигурационных файлов под конкретный сервер в момент деплоя.  


**Стек технологий**  


Веб-сервер и маршрутизация: Nginx  


Контейнеризация: Docker, Docker Compose  


Автоматизация инфраструктуры (IaaC): Ansible  


Мониторинг: Prometheus, Grafana
